## How to Run
Vite + React + TypeScript implementation of Connect Four.

Quick start

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

3. Run tests

   npm run test

Play: click the arrows above columns to drop pieces. Red (R) starts first.
